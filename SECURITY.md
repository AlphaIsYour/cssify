# Security Policy

## Supported Versions

We prioritize the security of Eno CSS Playground. The latest version on the `master` branch receives active security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Eno CSS Playground, please **do not report it through a public GitHub issue**.

Instead, please send an email to alphrenoorz@gmail.com with:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested remediations or mitigations.

You will receive an acknowledgment of your report within 48 hours. We appreciate your cooperation in responsible disclosure.
